# 連續 3D 世界換場 — 協作指南

所有功能在 index.html，無外部依賴。16:9 投影舞台使用 Canvas 2D 繪製真正的 3D 座標透視投影，CPU 深度排序，不是 WebGL。

- configs 定義四個世界，每個世界五個三維據點；spline 為封閉 Catmull–Rom 路徑，p 是可連續正負增長的站點座標。整數 p 代表到站；不要在第五站後重設 p。
- camera、avatar 使用同一條路徑連續計算位置，effects 依相鄰站點權重混合。歌詞交叉淡化，五頁內容可編輯。
- 保留正反向、直接跳頁經過中間站、自動循環、暫停與投影全螢幕。不要修改其他實驗室。
- 建議在 Chrome / Edge 實際測試四個模式各 1→2→3→4→5→1，反向 1→5，跳頁、暫停、全螢幕、手機及離線匯出。確認場景無跳切、事件可辨識、歌詞對比足夠；檢查長時間 CPU 使用率。模擬測試可驗證路徑但不可取代瀏覽器視覺測試。
