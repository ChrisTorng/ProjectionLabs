REFERENCE / IMPLEMENTATION

來源與技術界線

參考 Kittenjam Motion Library 的元件／動作時機／情境收藏概念，並以 既有轉場、文字效果、動態圖鑑 排除同質項目。目前已透過實際瀏覽器確認原站 CSS 動畫類別與具體項目，60 種效果涵蓋文字編排、頁面轉場與資訊動態；參考原站的效果提供對應編號，其餘為針對投影情境設計，並排除既有重複效果。所有 CSS 均為本專案重新實作，不直接複製原站程式。

動畫以 CSS Animations、transform、clip-path 實作。大部分換位由合成層處理；格片、陰影、裁切仍可能增加 Paint。開啟「減少動態」可直接切頁。沒有外部動畫套件或網路 API。
